# SiteCraft credit policy

Статус: Stage 0 canonical policy  
Дата: 19 июля 2026 года

## Кошельки

1. **AI SiteCraft**: генерация черновика, AI-разбор поискового намерения и новый Deal Finder анализ.
2. **Внешний источник**: provider search и provider detail, выполняемые Worker.
3. **Продвижения**: уже купленные одноразовые услуги для публичного объявления.

Кошельки нельзя складывать в одно число.

## Бесплатный AI-баланс

- дневное начисление: 5;
- максимум бесплатного накопления: 50;
- бесплатные списываются раньше платных;
- начисление и списание выполняются только сервером;
- повтор с тем же `idempotency_key` не меняет баланс второй раз.

## Стоимость действий

| Действие | Кошелёк | Стоимость |
| --- | --- | ---: |
| Просмотр страницы или ленты | Нет | 0 |
| Фильтр и локальная сортировка | Нет | 0 |
| Сохранить, скрыть, отметить просмотренным | Нет | 0 |
| AI-разбор поискового запроса | AI | 1 после успеха |
| AI-черновик объявления | AI | 1 после успеха |
| Новый Deal Finder AI-анализ | AI | 1 после успеха |
| Поиск внешнего источника | Provider | 1 после успешного вызова |
| Detail внешнего источника | Provider | 1 за успешный detail |
| Применить купленное продвижение | Promotion | 1 покупка |

## Канонический ответ `/me/credits`

```json
{
  "free_ai_credits": 5,
  "paid_ai_credits": 10,
  "ai_credits_total": 15,
  "ai_credits_used_total": 4,
  "free_ai_credits_daily_grant": 5,
  "free_ai_credits_cap": 50,
  "provider_credits_balance": null,
  "provider_credits_daily_limit": 5,
  "provider_credits_used_today": 2
}
```

Frontend продолжает принимать старое `ai_credits` или `credits`, но показывает разницу как «Ранее начисленные». После миграции Xano эти legacy-поля нельзя использовать для новых записей.

## `credit_ledger`

Минимальные поля:

- `id`, `user_id`, `wallet_type`;
- `delta`, `balance_after`, `reason`;
- `action`, `status`;
- `idempotency_key`, `provider_request_id`;
- `related_listing_id`, `related_purchase_id`;
- `created_at`.

Журнал неизменяемый. Возврат записывается новой положительной операцией, а не редактированием старой.

## Запреты

- не списывать до успешного результата;
- не списывать за HTTP/network/model error;
- не хранить баланс только в браузере;
- не называть provider-кредиты AI-кредитами;
- не запускать платный внешний поиск при обычной перезагрузке страницы;
- не скрывать цену действия до нажатия.
