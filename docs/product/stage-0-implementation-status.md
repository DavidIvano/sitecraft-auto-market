# Stage 0 implementation status

Дата: 19 июля 2026 года

## Реализовано в репозитории

- `/auth/me` подтверждает единичный `401` повторным запросом перед удалением сессии.
- Защищённые страницы кабинета, Deal Finder, модерация и Google callback используют подтверждение завершения сессии.
- `403`, `429` и временные ошибки не удаляют Bearer-токен.
- Deal Finder различает вход, роль, выключенный модуль, временную ошибку, rate limit и отсутствующее объявление.
- При валидном `/auth/me` и `401` отдельного Deal Finder endpoint показывается временная ошибка, а не выход.
- Добавлена совместимая нормализация legacy и canonical AI-балансов.
- Зафиксирована бесплатная AI-модель: 5 в день, накопление до 50.
- Бесплатные рабочие действия отделены от AI, provider и promotion расходов.
- Добавлен ограниченный журнал client events без PII.
- Политика конфиденциальности синхронизирована с техническими событиями.
- Добавлены контракты API-состояний, кредитов и измерения.

## Проверено

- `npm test`: 173/173;
- `npm run check`: 0 errors, 0 warnings, 0 hints;
- `npm run build`: 42 страницы;
- локальные `/dashboard/deal-finder/` и `/dashboard/billing/`: HTTP 200.

## Требует применения в Xano перед production-активацией всей кредитной модели

- добавить immutable `credit_ledger`;
- расширить `user_credits` на бесплатный и платный баланс;
- обновить `GET /me/credits` по `docs/product/credits-policy.md`;
- внедрить канонические error codes из `docs/contracts/api-state-contract.md`;
- добавить batch endpoint product events с allowlist, TTL и дедупликацией;
- перенести фактическое списание всех AI-действий в одну серверную функцию.

Эти пункты не следует отмечать опубликованными только на основании frontend-сборки. До миграции frontend сохраняет совместимость с текущими ответами Xano.

## Gate перед Stage 1

1. Применить и проверить Xano credit migration на тестовом пользователе.
2. Подтвердить, что ошибка AI возвращает кредит или не списывает его.
3. Выполнить авторизованный smoke test Chrome, iPad и телефона.
4. Проверить минимум два последовательных `401`, один `403`, один `429` и один `503`.
5. Зафиксировать исходные метрики за 3-7 дней или явно принять отсутствие baseline.
