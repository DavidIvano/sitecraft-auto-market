# Этап 3: сравнение и уведомления

Это четвёртый последовательный этап общей дорожной карты.

## Реализовано

- Выбор от двух до четырёх автомобилей из ленты и досье.
- Постоянная панель выбранных автомобилей и отдельная адаптивная таблица сравнения.
- Лучшие числовые значения отмечаются, отсутствующие сведения показываются как `Нет данных`.
- Раздел `Сохранённые` переименован в рабочий `Шорт-лист`; карточки показывают локальную заметку, решение и следующий шаг.
- Настройки Email и Web Push, событий, минимального Deal score, частоты и тихих часов.
- Локальный журнал доставки и дедупликация по `user + listing + event + version + channel`.
- Просмотр страниц, фильтрация и обновление ленты не создают событий доставки.

## Граница текущей версии

- Сравнение и настройки уведомлений пока хранятся в текущем браузере.
- Интерфейс не заявляет, что внешнее письмо или настоящий Web Push уже отправлены.
- Для синхронизации между устройствами и реальной доставки подготовлен `docs/xano/deal-finder-stage-3.xs`.
- Внешнюю доставку нельзя включать до настройки подтверждённого email-провайдера, VAPID/Web Push Worker и серверной проверки тихих часов.

## Включение серверного режима

1. Создать четыре таблицы из XanoScript: `deal_comparisons`, `deal_comparison_items`, `notification_preferences`, `notification_deliveries`.
2. Опубликовать пять browser endpoint-ов в закрытой Deal Finder API group.
3. Добавить Worker доставки с отдельным trigger secret и уникальным `dedupe_key` до внешнего вызова.
4. Подключить email-провайдера и VAPID-ключи только как server-side secrets.
5. Проверить переход из уведомления через `/login?next=...` на правильное досье.
6. После production QA включить `PUBLIC_DEAL_FINDER_STAGE3_API_ENABLED=true`.

## Критерии готовности

- В сравнении всегда 2–4 машины; пятая не добавляется.
- Неизвестное значение не становится нулём или выдуманной характеристикой.
- Пользователь может отключить каждый канал.
- Тихие часы корректно работают, включая интервал через полночь.
- Повтор одного `dedupe_key` для канала не создаёт вторую доставку.
- Ссылка уведомления ведёт к owner-scoped досье после проверки входа.
