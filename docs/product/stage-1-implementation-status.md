# Этап 1: публичный AI-подбор

Статус: реализован локально, готов к публикации после общей проверки релиза.

## Что внедрено

- единый сценарий на `/cars/`: запрос на обычном языке, редактируемые параметры и результаты;
- строгая нормализация ответа AI по разрешённым маркам, кузовам, топливу, коробкам и числовым диапазонам;
- уточняющие вопросы по бюджету и кузову, когда запрос недостаточно конкретный;
- полный ручной редактор параметров, включая топливо, коробку, год и пробег;
- видимые применённые параметры с удалением по одному;
- объяснение «Почему подходит» только по фактам объявления;
- восстановление нулевой выдачи через ослабление одного критерия;
- сохранение поиска из обычной и пустой выдачи;
- предварительное сообщение: ручные фильтры бесплатны, успешный AI-разбор стоит 1 AI-кредит;
- продуктовые события без текста запроса и персональных данных;
- адаптивная проверка на 1440, 1024, 768 и 390 CSS px.

## Проверяемые правила

- неизвестные значения от AI не попадают в URL и фильтры;
- отсутствующая характеристика не используется как причина совпадения;
- изменение фильтров, сортировка и просмотр каталога не расходуют AI-кредиты;
- пустая выдача не сбрасывается автоматически: пользователь сам выбирает, какой критерий ослабить;
- обычная HTML-форма остаётся рабочим запасным сценарием без JavaScript.

## Backend-контракт

- `POST /ai/search/intent` возвращает структурированные `filters`, `explanation`, `confidence` и `suggestions`;
- `POST /saved-searches` сохраняет текущие параметры только для вошедшего пользователя;
- каноническая стоимость `ai_search_intent` равна 1 AI-кредиту и применяется только после успешного ответа;
- фактическое списание и idempotency должны оставаться серверной ответственностью Xano, а не браузера.
