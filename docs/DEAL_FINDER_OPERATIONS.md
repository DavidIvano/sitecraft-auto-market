# Deal Finder: production runbook

Статус на 18 июля 2026 года: модуль работает на основном сайте
`https://sitecraft-auto-market.pages.dev/dashboard/deal-finder/` в реальном Xano-режиме.
Cloudflare Worker опубликован по адресу
`https://sitecraft-deal-finder-sync.ivanovdavid19.workers.dev`.

## Как работает система

1. Cloudflare Worker один раз в сутки, в `06:15 UTC`, запрашивает один активный профиль поиска в Xano.
2. Kleinanzeigen Agent возвращает до 100 кандидатов за один search-credit.
3. Worker отделяет уже известные внешние ID от новых. Detail-данные он получает максимум для четырёх новых объявлений; существующим обновляет только безопасные отметки времени и статус источника.
4. Xano сохраняет предложения в изолированном Deal Finder. Публичная таблица `car_listings` не изменяется.
5. Браузер загружает только записи текущего авторизованного владельца. Xano проверяет роль и владельца на каждом запросе.
6. Кнопка AI на детальной странице создаёт версионируемую задачу в Xano. Worker проверяет очередь каждые две минуты и обрабатывает не больше одной задачи за запуск.
7. Worker отправляет в OpenAI только нормализованные характеристики и текст объявления. Изображения, ссылка источника, контакты продавца, raw provider data и секреты не передаются.

## Как пользоваться

1. Войти на основном сайте через обычный вход или Google.
2. Открыть `Кабинет` -> `Deal Finder`.
3. Использовать поиск, марку, максимальную цену, диапазон оценки и сортировку.
4. `Сохранить` добавляет карточку во вкладку `Сохранённые`.
5. `Отметить просмотренным` снимает признак нового объявления.
6. `Скрыть` переносит карточку во вкладку `Скрытые`; `Восстановить` возвращает её в ленту.
7. `Подробнее` открывает все сохранённые данные, галерею и AI-блок.
8. `Запустить AI-анализ` ставит задачу в очередь. Страница автоматически проверяет результат до двух минут. `Запустить повторно` создаёт новую историческую версию, не удаляя прежнюю.
9. Перед звонком или покупкой обязательно открыть оригинал и проверить актуальность, документы и техническое состояние самостоятельно.

## Что подключено

- Основной frontend: Cloudflare Pages, проект `sitecraft-auto-market`.
- API, авторизация, роли, данные и очередь: Xano, API group `sitecraft-auto-market` (`jAAj839u`).
- Источник предложений: Kleinanzeigen Agent REST API.
- AI: OpenAI Responses API, модель `gpt-5.6-luna`, strict structured output, `store=false`.
- Фоновая обработка: Cloudflare Worker `sitecraft-deal-finder-sync`.
- Расписание: AI каждые две минуты; поиск источника один раз в сутки в `06:15 UTC`.
- Free-бюджет источника: один search-credit для просмотра до 100 кандидатов и максимум четыре detail-credit в сутки, всего не более пяти Agent-кредитов за плановый запуск.
- Ручная синхронизация источника в production отключена. Просмотр ленты, фильтры и пользовательские действия работают через Xano и Agent-кредиты не расходуют.
- Google OAuth: существующий вход SiteCraft Auto Market на production origin.

Не подключены: Gmail/почтовый парсер, Telegram, автоматический контакт с продавцом, R2-копирование внешних изображений, CAPTCHA bypass и автоматический вход в Kleinanzeigen.

## Доступы

Доступ к Deal Finder выдаётся в Xano, таблица `automarket_users`, поле `role`:

- `deal_finder_admin` — доступ только к Deal Finder;
- `admin` — административный доступ сайта и Deal Finder;
- любая другая роль — Deal Finder закрыт сервером.

После смены роли пользователю нужно выйти и войти снова. Для отзыва доступа изменить роль на обычную пользовательскую. Удалять пользователя или добавлять auth-обход в frontend не требуется.

Инфраструктурные доступы выдаются отдельно:

- Cloudflare — через Members/Access соответствующего аккаунта; здесь Pages и Worker.
- Xano — через workspace members; здесь таблицы, endpoints и роли.
- OpenAI — API key хранится только как Cloudflare Worker Secret.
- Kleinanzeigen Agent — provider key хранится только как Cloudflare Worker Secret.
- Worker trigger и Xano ingest secret — только server-to-server; сотрудникам для работы в браузере они не нужны.

Секреты нельзя отправлять в чаты, добавлять в `PUBLIC_` variables, исходники, документацию, браузер или скриншоты.

## Польза системы

- Собирает внешние предложения в одной рабочей ленте.
- Не смешивает их с публичными объявлениями Auto Market.
- Убирает повторную ручную проверку уже найденных ID.
- Позволяет быстро сортировать по цене и первичной AI-оценке.
- Сохраняет рабочие статусы: новое, просмотрено, сохранено, скрыто.
- Формирует список рисков, недостающих данных и вопросов продавцу.
- Хранит историю повторных анализов для аудита.

AI score — приоритет для ручной проверки, а не техническая диагностика, рыночная оценка или гарантия прибыли.

## Production-показатели

- Первый набор: listings `1`-`5`.
- Контрольный повтор listing `1`: новая историческая AI-строка, прежняя сохранена.
- Финальная production-синхронизация: пять новых detail-записей `8`-`12`, `detailFailures=0`, `rejected=0`.
- Ограничения: один профиль, до 100 поисковых кандидатов, до четырёх новых detail-записей за суточный sync, одна AI-задача за Worker run.
- На момент финальной проверки AI queue была пустой: `processed=0`, `failed=0`.

## Аварийное отключение

1. Остановить Cron и выставить Worker flags `DEAL_FINDER_SYNC_ENABLED=false`, `DEAL_FINDER_AI_ENABLED=false`.
2. При необходимости пересобрать Pages с `PUBLIC_DEAL_FINDER_ENABLED=false`.
3. Не удалять таблицы и историю анализов: они нужны для аудита и безопасного восстановления.
