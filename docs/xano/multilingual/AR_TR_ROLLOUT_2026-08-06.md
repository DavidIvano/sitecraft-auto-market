# Добавление арабского и турецкого языков

Дата: 6 августа 2026 года.

## Сайт

- В общий allowlist добавлены `ar` и `tr`; полный набор: `de`, `ru`, `uk`, `en`, `ar`, `tr`.
- Для арабского используется `lang="ar"` и `dir="rtl"`; для турецкого — `lang="tr"` и `dir="ltr"`.
- Добавлены locale-теги для `hreflang`, переключатель языков, форматирование чисел и валют, основные словари страниц, каталог, карточка автомобиля и канонические значения характеристик.
- Сгенерированы 1361 пары арабских и турецких переводов статических интерфейсных фраз. Ключевая автомобильная терминология дополнительно отредактирована вручную.
- Новые translation jobs для объявлений по умолчанию включают цели `ar` и `tr`.

## Xano production

Перед изменением сохранены live-копии шести endpoint'ов в `live-backup-2026-08-06-ar-tr/` вместе с SHA-256 manifest.

В таблицу `locales` (`873236`) добавлены:

- `ar`: `العربية`, направление `rtl`, `is_active=true`, `is_public=true`;
- `tr`: `Türkçe`, направление `ltr`, `is_active=true`, `is_public=true`.

Сначала как draft, затем после успешной компиляции опубликованы:

- `GET /cars` (`3966698`);
- `GET /cars/{slug}` (`3966699`);
- `GET /cars/{slug}/seller-listings` (`3985671`);
- `GET /cars/{slug}/related` (`3999920`);
- `GET /locales` (`4005564`);
- `GET /taxonomies` (`4005565`).

Production smoke-тест подтвердил HTTP 200 для `ar` и `tr` на всех шести публичных контрактах. `GET /locales` возвращает шесть разрешённых языков, а неизвестный `lang=fr` по-прежнему отклоняется с HTTP 400.

## Fallback объявлений

Интерфейс и канонические характеристики переводятся сразу. Свободные тексты продавца используют безопасный исходный fallback, пока в `car_listing_translations` нет завершённого перевода соответствующей локали. Массовый запуск новых `ar`/`tr` jobs остаётся отдельным контролируемым этапом очереди переводов.
