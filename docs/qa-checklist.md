# QA Checklist

## Auth

- Гость видит `Войти`, `Регистрация`, `Добавить объявление`.
- Авторизованный пользователь видит `Кабинет`, `Выйти`.
- Админ видит `Модерация`.
- Неавторизованный пользователь при переходе в кабинет попадает на `/login?next=...`.

## Manual listing flow

- Можно создать объявление вручную.
- Можно загрузить до 5 фото.
- Все фото сохраняются в R2 и передаются в Xano как `image_url`.
- После создания объявление уходит в `pending_review`.
- После approve оно появляется в каталоге.
- Страница `/cars/{slug}` открывается по slug и показывает все фото без дублей.

## AI draft flow

- AI загружает 1-8 фото.
- AI создает `ai_draft`, но не публикует объявление сразу.
- Пользователь видит confidence, missing fields, warnings.
- Пользователь может отредактировать поля.
- `Подтвердить данные` не пропускает невалидный VIN, год, цену, пробег, город.
- `Отправить на модерацию` доступна только после подтверждения данных.

## Admin

- Admin endpoints проверяют роль через таблицу `automarket_users`.
- Approve, reject, delete, sold работают без ошибки `$auth.role`.
- Delete переводит объявление в `deleted`, а не удаляет физически без следа.
- Sold переводит объявление в `sold`, карточка получает метку `Продано`.
- Добавление/удаление/главное фото работает через `image_url`.

## SEO

- `/sitemap.xml` содержит публичные approved/published/sold объявления.
- `/robots.txt` открыт для каталога и закрывает `/dashboard/`, `/admin/`.
- `/cars/{slug}` содержит title, description, canonical, Open Graph и structured data.

## Legal

- `/privacy` доступна.
- `/impressum` доступна.
- Контакт поддержки: `support@sitecraft.agency`.
