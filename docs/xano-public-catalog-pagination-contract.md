# Xano: контракт серверной пагинации публичного каталога

Статус: frontend-клиент подготовлен (`getApprovedCarsPage`), но переключать основной каталог на него можно только после публикации этого контракта в Xano. До этого функция распознаёт старый массив и делает совместимый локальный `slice`, не ломая сайт.

## Endpoint

`GET /cars` и `GET /public/locale/cars`

Параметры:

- `lang`: поддерживаемый код языка;
- `page`: целое число от 1, по умолчанию 1;
- `limit`: целое число 1–24, по умолчанию 24;
- `sort`: `newest`, `price_asc`, `price_desc`, `mileage_asc`;
- фильтры: `vehicle_type`, `body_type`, `brand`, `model`, `city`, `fuel_type`, `transmission`, `price_min`, `price_max`, `year_min`, `year_max`, `mileage_max`.

Порядок выполнения в Xano должен быть фиксированным:

1. Только публичные объявления: `status=approved|published`, `moderator_approved=true`, без `deleted`, `blocked`, `archived` и черновиков.
2. Применить фильтры.
3. Премиальные объявления с активным сроком продвижения поставить выше обычных.
4. Применить выбранную сортировку внутри каждой группы.
5. Посчитать `total` после фильтров, до пагинации.
6. Применить offset `(page - 1) * limit` и limit.
7. Вернуть только поля публичной карточки, перевод запрошенного языка и данные изображений; исключить приватные контакты, VIN и внутренние поля модерации.

## Ответ 200

```json
{
  "items": [],
  "page": 1,
  "limit": 24,
  "total": 137,
  "has_next": true,
  "sort": "newest",
  "filters": {}
}
```

Обязательные гарантии:

- одинаковый запрос возвращает стабильный порядок;
- `id` используется как последний tie-breaker сортировки;
- неизвестный фильтр не игнорируется молча: `400 INVALID_FILTER`;
- `limit > 24` нормализуется до 24 или возвращает `400`;
- endpoint не делает N+1-запросы изображений/переводов;
- ответ получает CDN TTL 60 секунд и `stale-while-revalidate`;
- время Xano endpoint фиксируется в логах, целевой p95 — до 500 мс.

## Release gate

- page 1 и page 2 не имеют общих `id`;
- сумма страниц равна `total` на стабильном snapshot;
- premium остаётся первым;
- все фильтры проверены отдельно и в комбинации;
- `lang` возвращает только готовый перевод для strict SEO-маршрута;
- payload одной страницы не превышает 250 КБ без изображений;
- после gate каталог переводится с `getApprovedCars` на `getApprovedCarsPage`.
